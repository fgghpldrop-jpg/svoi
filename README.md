# 📍 СВОИ — Гиперлокальная сеть Бобруйска

> **«СВОИ»** — это мобильная социальная экосистема реального времени для молодежи города Бобруйск (Беларусь), объединяющая гео-позиционирование, клановую механику со стриками, тепловую карту активности на базе Uber H3 и интерактивную кибер-карту с геофенсингом границ города.

---

## 🌟 Ключевые возможности

- 🗺️ **Интерактивная карта и Кибер-Барьер**:
  - Точный 319-точечный полигон официальных границ Бобруйска (`bobruyskBoundary.json`).
  - Инвертированная маска затемнения мира за пределами города (`#07090E`, opacity 88%).
  - Неоновый анимированный периметр кибер-барьера (`#10B981` / `#34D399`).
  - Предупреждающий HUD-баннер при выходе за пределы зоны действия сети.
- ⬡ **Тепловая карта активности (Uber H3)**:
  - Динамическая визуализация плотности скопления молодежи по гексагонам H3 (Resolution 9).
  - Градация загруженности (зеленый/янтарный/красный) с капсулами количества участников.
- 🛡️ **Кланы и Механика стриков**:
  - Создание и вступление в городские кланы (до 15 человек).
  - Поддержание ежедневных стриков (прогулки кворумом $K \ge \lceil N \times 0.6 \rceil$).
  - Заморозка стриков («Щит клана») через маркет наград.
- 💬 **Мессенджер и SignalR Realtime**:
  - Клановые и личные чаты в реальном времени.
  - Мгновенная доставка сообщений и обновлений гео-статусов.
- 🎁 **Партнерский маркет и Flash-события**:
  - Интеграция локальных заведений Бобруйска (Социалка, Тайм-клуб 1387, Бобруйск-Арена, Додо).
  - Начисление баллов за активность и обмен на промокоды и скидки.
  - Flash-новости с ограниченным таймером действия.
- 🤖 **AI-генерация био**:
  - Персонализированное саммари профиля в стиле уличного вайба Бобруйска на базе Google Gemini.

## 🏗️ Архитектура и стек технологий

### Backend (`/backend`)
- **Стек**: .NET 8 (C# 12), ASP.NET Core Web API
- **База данных**: PostgreSQL + Entity Framework Core (Code-First миграции)
- **Гео-пространственная обработка**: Uber H3 (H3.Core), NetTopologySuite
- **Realtime**: SignalR Hubs (`/hubs/map`, `/hubs/chat`)
- **Аутентификация**: JWT Bearer + Telegram Bot код-верификация
- **Фоновые задачи**: BackgroundService воркеры пересчета тепловой карты и валидации стриков кланов

### Mobile (`/mobile`)
- **Стек**: React Native + TypeScript
- **Картография**: `@maplibre/maplibre-react-native` + `@turf/turf`
- **Иконки & UI**: `lucide-react-native`, `react-native-svg`
- **Дизайн-система**: Urban Dark Glassmorphism (графит `#0B0E14`, неон `#10B981`, скругленные сквирклы)

## 🚀 Быстрый старт

### Требования
- [.NET 8 SDK](https://dotnet.microsoft.com/download)
- [Node.js 18+](https://nodejs.org/)
- [PostgreSQL 15+](https://www.postgresql.org/) (локально или в Docker)

### Запуск Backend
```bash
cd backend
dotnet restore
dotnet build
dotnet run --project src/Svoi.Api
```
API будет доступен по адресу `http://localhost:5000` (Swagger UI: `http://localhost:5000/swagger`, Веб-превью: `http://localhost:5000/preview/index.html`).

### Запуск Mobile
```bash
cd mobile
npm install
npm start
```
